## 2. Objetivo e mecanismo causal

Entropia de Shannon mede a distribuição de símbolos: H = −Σ p(b) log2 p(b), em bits por byte. Para bytes, 0 ≤ H ≤ 8. Essa estatística ignora a ordem: repetir 00..FF tem H=8 embora seja perfeitamente previsível. Compressão muda frequências e remove redundância; cifras e certos dados comuns também podem ter distribuições uniformes. Portanto, H alto é uma pista de conteúdo, não uma classificação de malware ou packing. A estimativa depende do tamanho da amostra; compare tamanhos e janelas.

## 4. Exemplo resolvido — estado, decisão e efeito

Para AABB, p(A)=p(B)=1/2: cada parcela vale 1/2 e H=1. Para AAAA, H=0. Em entropy-uniform.bin cada um dos 256 bytes aparece 16 vezes: H=8. mixed.bin contém 2048 zeros seguidos de 2048 bytes pseudoaleatórios com semente 160. As duas primeiras janelas de 1024 têm H=0; as seguintes têm H perto de 8. Uma entropia da distribuição global esconderia essa fronteira. compressed.bin usa zlib e mede poucos bytes, por isso não deve ser comparado cegamente ao random.bin de 4096 bytes.

## 7. Código comentado e artefatos

```python
from collections import Counter
from math import log2
def entropy(data):
    if not data: return 0.0  # convenção explícita para amostra vazia
    counts = Counter(data)
    return -sum((n / len(data)) * log2(n / len(data))
                for n in counts.values())  # probabilidades observadas
```

## 10. Defesa e reteste

Use entropia para priorizar investigação, acompanhada de formato, strings, seções e proveniência. O controle contra falso positivo é a fixture uniforme previsível: H=8 não a transforma em malware. Reteste a mesma medição após compressão e após descompressão; o conteúdo recuperado deve ser byte a byte igual ao texto.

## 11. Troubleshooting específico

Se a entropia superar 8, revise normalização e base do log. Um arquivo de um byte tem H=0 mesmo que venha de gerador aleatório. Janela final curta deve ser identificada pelo tamanho, não tratada como observação equivalente.

## 14. Quiz

### 1. H=8 prova aleatoriedade imprevisível?
A. Sim, por definição
B. Somente acima de 1 KiB
C. Não; 00..FF repetido também produz H=8
D. Somente após zlib

**Resposta:** C. Shannon por frequência de byte não mede previsibilidade da sequência.

### 2. Para AABB, qual H?
A. 1 bit/byte
B. 2 bits/byte
C. 4 bits/byte
D. 8 bits/byte

**Resposta:** A. Há dois símbolos equiprováveis: −2×0,5×log2(0,5)=1.

### 3. Por que usar janelas em mixed.bin?
A. Para eliminar a necessidade de ler bytes
B. Para comprovar execução maliciosa
C. Para garantir H global maior
D. Para localizar a transição entre regiões de distribuições diferentes

**Resposta:** D. Janelas preservam informação espacial perdida na entropia da distribuição global.
