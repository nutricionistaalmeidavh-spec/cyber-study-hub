**Trilha:** Projeto Final Integrado / Capstone geral (não apenas IA)  
**Revisão:** A técnico-editorial assistida por IA; não certificação ou nota de aluno  
**Tempo sugerido:** 60–100 minutos  
**Pré-requisito recomendado (não bloqueante):** aulas 209–210; escopo aprovado e threat model.  
**Núcleo obrigatório:** R$ 0, Node.js 22+, arquivos locais e fixtures sintéticas; sem conta, cloud, API, GPU ou assinatura.

## Problema e objetivo verificável

**Fase:** Observabilidade. Sem UTC, identidade, ação, recurso e versão, um log 'acesso realizado' não distingue um erro de autorização de comportamento correto.

**Objetivo:** Reconstruir a sequência de decisões do capstone a partir de eventos sintéticos correlacionáveis.

**Entrega:** `TIMELINE.csv`, vinculada ao mesmo ativo `F001` do laboratório EscolaLab.

## Fundamentos e mecanismo causal

Log de auditoria descreve decisão observada, não sua legitimidade. A classificação observed emitida em 200 não significa 'autorizado'. Fonte, carimbo temporal e modo são essenciais para interpretação.

makeAuditEvent devolve timestamp, asset, identity, action, status, mode e classification. A detecção da aula 215 avaliará o status de Bob junto com o contexto da fixture, nunca uma palavra isolada.

O fluxo completo é `escopo → inventário → hipótese → prova mínima → logs → detecção → correção → reteste → relatório`. Cada resultado desta aula deve referenciar entrada, esperado, observado e limite; a identidade `?as=` da aplicação é **simulada, não autenticação**.

## Exemplo resolvido — preveja antes de executar

Na raiz do repositório, salve o código como `exemplo-214.mjs` e execute `node exemplo-214.mjs`. Não use o REPL para imports estáticos. Os arquivos de código citados são do mesmo checkout do Hub; não instale dependências adicionais.

```js
import {decideRead,makeAuditEvent} from './public/course-labs/capstone-final/model.mjs';
const at=['2026-10-15T12:00:00.000Z','2026-10-15T12:00:01.000Z'];
const events=[
 makeAuditEvent({actor:'bob',mode:'vulnerable',result:decideRead({actor:'bob',mode:'vulnerable'}),at:at[0]}),
 makeAuditEvent({actor:'bob',mode:'corrected',result:decideRead({actor:'bob'}),at:at[1]})
];
console.log(events.map(e=>JSON.stringify(e)).join('\n'));
```

**Resultado esperado:** Dois JSONs em UTC: Bob status 200 no modo vulnerable; Bob status 403 no corrected. O nome classification não substitui avaliação contextual.

**Contraprova/erro comum:** Se os timestamps não tiverem ordenação confiável, identifique a lacuna; nunca invente eventos ausentes nem conclua 'nenhum incidente' apenas por falta de log.
