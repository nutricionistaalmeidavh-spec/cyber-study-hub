## Problema e objetivo

Um script usa um módulo da própria pasta e uma dependência instalada. Precisamos reproduzir o resultado 2.0 KiB em um ambiente separado, sem instalar pacotes globalmente nem depender da internet.

## Mecanismo e exemplo resolvido

Um módulo é um arquivo importável. PY-08 importa conversao da pasta do script; conversao importa medidas_lab de site-packages do ambiente virtual. venv cria um interpretador associado a diretórios próprios de pacotes; não é uma VM nem isola permissões de arquivos ou rede. requirements fixa a versão 1.0.0 da dependência didática fornecida como wheel local completo.

Fluxo: PY-08.py → conversao.resumo(2048) → medidas_lab.kib(2048) → 2.0 → "2.0 KiB". `sys.executable` deve apontar para .venv e `medidas_lab.__file__` para site-packages dentro dela. O nome da distribuição usa hífen (medidas-lab); o módulo importado usa underscore (medidas_lab).

```python
from medidas_lab import kib

def resumo(tamanho):
    return f"{kib(tamanho):.1f} KiB"
```

## Laboratório reproduzível

Arquivos: [PY-08.py](/course-labs/phase16-foundations/PY-08.py), [conversao.py](/course-labs/phase16-foundations/conversao.py), [requirements-PY-08.txt](/course-labs/phase16-foundations/requirements-PY-08.txt), [medidas_lab-1.0.0-py3-none-any.whl](/course-labs/phase16-foundations/medidas_lab-1.0.0-py3-none-any.whl). Baixe os arquivos para uma pasta própria e mantenha os nomes.

```sh
python3 -m venv ".venv"
".venv/bin/python" -m pip install --no-index --find-links . -r "requirements-PY-08.txt"
".venv/bin/python" "PY-08.py"
```

## Prática e autoexplicação

Baixe todos os quatro arquivos para a mesma pasta. Parcial: mude o argumento para 1024 e preveja o resultado. Independente: execute PY-08.py com o Python fora de .venv e explique o ModuleNotFoundError caso a dependência não esteja instalada ali. Autoexplicação: por que usar o mesmo executável em -m pip e na execução do script?

## Solução comentada e checkpoints

1024 gera 1.0 KiB. Checkpoints: pip informa medidas-lab 1.0.0 instalada; a saída mostra o caminho do interpretador da venv; o módulo conversao vem da pasta local. Windows: `py -3 -m venv .venv`, depois `& ".venv\Scripts\python.exe" -m pip install --no-index --find-links . -r "requirements-PY-08.txt"` e o mesmo executável para PY-08.py.

## Robustez, reteste e diagnóstico

Se venv não estiver disponível em Linux, instale o componente python3-venv pelo gerenciador do sistema. Não nomeie o script medidas_lab.py: isso pode sombrear a dependência. Se pip buscar rede, confira --no-index. Fixar versão torna a resolução previsível, mas não prova a confiança no fornecedor. Reteste após remover somente a venv criada para este lab e recriá-la a partir do wheel.
