## Problema e objetivo

Um arquivo UTF-8 contém Ana, João e uma linha vazia. Gere um resumo com dois registros, sem destruir o resumo anterior quando o arquivo de origem não existir.

## Mecanismo e exemplo resolvido

Path representa o caminho sem abri-lo. open("r",encoding="utf-8") decodifica bytes em texto; with fecha o handle em saída normal e excepcional. strip remove quebra de linha e espaços nas bordas; a condição descarta linha vazia. O destino só é aberto em modo w depois da leitura: abrir w antes truncaria um resumo válido mesmo se a origem estivesse ausente.

Bytes UTF-8 de João são decodificados para quatro caracteres. A coleção passa de [] para [Ana] para [Ana,João]; a linha vazia não entra. O destino recebe `registros=2
`. Na segunda chamada, FileNotFoundError acontece na abertura da origem; a escrita nunca começa.

```python
from pathlib import Path
import tempfile


def resumir(origem, destino):
    # with fecha cada arquivo mesmo se a leitura ou escrita lançar exceção.
    with Path(origem).open("r", encoding="utf-8") as entrada:
        nomes = [linha.strip() for linha in entrada if linha.strip()]
    # Somente escrevemos depois de a leitura inteira terminar com sucesso.
    with Path(destino).open("w", encoding="utf-8", newline="\n") as saida:
        saida.write(f"registros={len(nomes)}\n")
    return nomes

if __name__ == "__main__":
    # Pasta temporária própria: não sobrescreve documentos do aluno.
    with tempfile.TemporaryDirectory(prefix="aula arquivos ") as pasta:
        base = Path(pasta)
        origem, destino = base / "nomes ação.txt", base / "resumo.txt"
        origem.write_text("Ana\nJoão\n\n", encoding="utf-8")
        assert resumir(origem, destino) == ["Ana", "João"]
        assert destino.read_text(encoding="utf-8") == "registros=2\n"
        try:
            resumir(base / "ausente.txt", destino)
        except FileNotFoundError:
            print("ausente: arquivo não encontrado; resumo preservado")
        else:
            raise AssertionError("ausente deveria falhar")
        assert destino.read_text(encoding="utf-8") == "registros=2\n"
        print("UTF-8: João; registros=2; caminhos com espaços OK")
```

## Prática e autoexplicação

Parcial: acrescente uma linha de nome e preveja o novo resumo. Independente: modifique resumir para também retornar a quantidade de linhas vazias, sem criar outro acesso de leitura. Autoexplicação: em que linha o destino seria perdido se sua abertura fosse movida para antes da leitura?

## Solução comentada e checkpoints

Três nomes produzem registros=3. Uma solução independente incrementa vazias quando `not linha.strip()` e mantém nomes em lista separada; o fixture original tem uma linha vazia. Checkpoints: João deve preservar o ã; ausência da origem deve manter o resumo existente byte a byte.

## Robustez, reteste e diagnóstico

Modo w sobrescreve; use apenas o destino de laboratório. Falha durante a escrita ainda pode deixar arquivo parcial: para uma ferramenta real, escreva em temporário no mesmo filesystem e substitua após sucesso. UnicodeDecodeError indica encoding incompatível, não caminho ausente; não o capture como FileNotFoundError. Reteste origem ausente, arquivo vazio e caminho com espaços.

2. **Qual construção fecha o arquivo mesmo com exceção?**

3. **Por que encoding explícito?**
   - A) para decodificar os bytes de modo previsível

**Gabarito comentado:** 1: B — a abertura em w já remove o conteúdo anterior. 2: C — o gerenciador de contexto executa o fechamento. 3: A — UTF-8 determina a interpretação de João.
