## Problema e objetivo

Copie Ana para um buffer de cinco bytes e recuse ABCDE sem corromper o conteúdo anterior. A decisão depende de comprimento mais terminador, não só do número de letras.

## Mecanismo e exemplo resolvido

String C é uma sequência de bytes terminada por NUL, byte de valor zero. "Ana" ocupa quatro bytes: A,n,a,0; strlen retorna 3 e sizeof destino retorna 5. copiar verifica n<cap e só então copia n+1 bytes, incluindo NUL. O contrato exige src já terminada e destino sem sobreposição; strlen não torna dados arbitrários seguros.

Ana: n=3, cap=5 → copia 4 bytes. ABCD: n=4 → copia 5 bytes, limite exato. ABCDE: n=5 → recusa e preserva ABCD. O retorno 1 significa sucesso; 0 significa falta de capacidade. `\0` é terminador; não é o caractere textual "0".

```c
#include <assert.h>
#include <stdio.h>
#include <string.h>
/* Contrato: src é string válida; dst tem cap bytes graváveis. */
static int copiar(char *dst, size_t cap, const char *src) {
    size_t n = strlen(src);
    if (n >= cap) return 0; /* reserva um byte para o terminador NUL */
    memcpy(dst, src, n + 1); /* inclui o terminador; objetos sem sobreposição */
    return 1;
}
int main(void) {
    char destino[5] = "";
    assert(copiar(destino,sizeof destino,"Ana"));
    printf("texto=%s comprimento=%zu capacidade=%zu\n",destino,strlen(destino),sizeof destino);
    assert(copiar(destino,sizeof destino,"ABCD"));
    assert(!copiar(destino,sizeof destino,"ABCDE"));
    assert(strcmp(destino,"ABCD") == 0); /* recusa preserva destino */
    puts("4 caracteres aceitos; 5 recusados; destino preservado");
    return 0;
}
```

## Prática e autoexplicação

Parcial: qual capacidade mínima aceita Ana? Independente: adicione teste de texto vazio e capacidade zero usando buffer real; preveja se alguma escrita ocorre. Autoexplicação: por que comparar n>cap em vez de n>=cap permitiria um byte a mais?

## Solução comentada e checkpoints

Capacidade mínima 4. Texto vazio precisa de um byte para NUL; cap=0 recusa antes de escrever. Checkpoint: recusa deve manter destino ABCD. Não use strlen em um array sem terminador para tentar descobrir quanto ele suporta.

## Robustez, reteste e diagnóstico

Em UTF-8, letras acentuadas podem ocupar vários bytes: o tamanho relevante para este buffer é bytes, não caracteres visuais. Se a saída tiver lixo, procure NUL ausente; se truncar silenciosamente, confira o contrato de recusa. Reteste comprimentos 0,cap−1,cap. Para fontes com tamanho conhecido e sem NUL, desenhe uma API que receba o comprimento explícito.

## Quiz

1. **strlen("Ana") é:**
   - A) 4
   - B) 3
   - C) 5

2. **Um buffer de cinco bytes comporta no máximo:**
   - A) 5 bytes de texto e NUL
   - B) 3 bytes de texto
   - C) 4 bytes de texto e NUL

3. **Na recusa de ABCDE, destino fica:**
   - A) ABCD
   - B) ABCDE
   - C) vazio

**Gabarito comentado:** 1: B — não conta o terminador. 2: C — um byte precisa ser reservado. 3: A — a função verifica antes da cópia.

## Flashcards

- **NUL** → Byte zero que termina uma string C.
- **Comprimento** → Quantidade de bytes antes de NUL, medida por strlen.
- **Capacidade** → Bytes disponíveis no destino, incluindo espaço para terminador.
