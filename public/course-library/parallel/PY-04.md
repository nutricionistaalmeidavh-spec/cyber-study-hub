## Problema e objetivo

Uma rotina de preço precisa devolver 750 para 250 centavos × 3 itens e recusar True como preço. Escreva e teste um contrato de função, distinguindo nomes locais, argumentos e retorno.

## Mecanismo e exemplo resolvido

`def` cria uma função; sua execução começa quando ela é chamada. preco e quantidade recebem argumentos. `valor` local existe durante a chamada, enquanto o valor=99 do chamador permanece 99. `return` encerra a chamada e entrega o produto. Python trata bool como subtipo de int, por isso `type(x) is int` expressa este contrato mais restrito que `isinstance(x,int)`.

Chamada subtotal(250,3): valida tipos → valida sinais → valor local 750 → retorna 750. subtotal(250,0) retorna 0. subtotal(-1,2) interrompe com ValueError antes da multiplicação. O teste consulta resultados; imprimir 750 sozinho não verificaria o retorno.

```python
def subtotal(preco, quantidade):
    """Recebe centavos/quantidade inteiros não negativos; retorna centavos."""
    # bool é subtipo de int em Python; este contrato recusa bool explicitamente.
    if type(preco) is not int or type(quantidade) is not int:
        raise TypeError("esperados inteiros")
    if preco < 0 or quantidade < 0:
        raise ValueError("valores negativos")
    valor = preco * quantidade  # variável local; não altera o chamador
    return valor

if __name__ == "__main__":
    valor = 99
    assert subtotal(250, 3) == 750
    assert subtotal(250, 0) == 0
    assert valor == 99
    for args, erro in [((-1, 2), ValueError), ((True, 2), TypeError)]:
        try:
            subtotal(*args)
        except erro:
            pass
        else:
            raise AssertionError(f"deveria rejeitar {args}")
    print("subtotal=750; zero=0; externo=99; inválidos rejeitados")
```

## Prática e autoexplicação

Parcial: acrescente um teste para subtotal(0,3). Independente: escreva uma função total(preco,quantidade,frete) que use subtotal, valide frete inteiro não negativo e retorne a soma. Autoexplicação: por que valor global continua 99 mesmo havendo uma variável local homônima?

## Solução comentada e checkpoints

Zero × três retorna zero. Uma solução de total valida frete com as mesmas duas verificações e devolve `subtotal(preco,quantidade)+frete`; total(250,3,150)=900. Checkpoint: teste inválido deve falhar se o raise for retirado; a ausência de exceção não pode ser confundida com sucesso.

## Robustez, reteste e diagnóstico

Evite capturar todas as exceções dentro de subtotal e retornar zero: isso tornaria entrada defeituosa indistinguível de compra vazia válida. Reteste bool, negativo, zero e valor normal. Se retorno for None, procure caminho sem return. Se externo mudar, procure global ou mutação de objeto compartilhado.

## Quiz

1. **Qual é o retorno de subtotal(250,0)?**
   - A) None
   - B) erro de tipo
   - C) 0

2. **Por que bool é recusado explicitamente?**
   - A) bool é subtipo de int
   - B) bool e int são tipos sem relação de herança
   - C) True é convertido automaticamente em string na multiplicação

3. **O valor externo após a chamada é:**
   - A) 750
   - B) 99
   - C) 0

**Gabarito comentado:** 1: C — zero está no domínio aceito. 2: A — o domínio desejado é mais estrito que a hierarquia de tipos. 3: B — a atribuição local não muda o nome do chamador.
