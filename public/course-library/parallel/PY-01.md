## Problema e objetivo

Execute um arquivo Python que cumprimenta Ana e informa três itens. A competência desta aula é salvar código, invocar o interpretador correto e explicar quais linhas pertencem ao bloco condicional.

## Mecanismo e exemplo resolvido

Python lê o arquivo fonte UTF-8 e interpreta as instruções em ordem. `nome` recebe texto; quantidade recebe inteiro. Os dois pontos abrem o bloco do if e os quatro espaços colocam o primeiro print dentro dele. O segundo print está alinhado com if e executa independentemente da condição. Aspas delimitam texto; a f-string avalia os nomes entre chaves.

Com quantidade=3, a condição é verdadeira e a saída tem duas linhas: `Olá, Ana: 3 itens` e `Fim`. Com quantidade=0, o primeiro print é pulado e somente `Fim` aparece. Não escreva o marcador `>>>` do console interativo no arquivo.

```python
# Salve este arquivo como primeiro.py em UTF-8.
nome = "Ana"
quantidade = 3
if quantidade > 0:
    print(f"Olá, {nome}: {quantidade} itens")  # quatro espaços: corpo do if
print("Fim")  # fora do bloco: executa mesmo com quantidade zero
```

## Oficina completa — da primeira execução à depuração consciente

**Se você nunca usou um terminal:** ele é uma janela para pedir ao computador que execute comandos. `python3` é o programa interpretador; `PY-01.py` é o arquivo com seu código. O texto `>>>` pertence ao modo interativo do Python e **não** deve ser digitado dentro do script. No Windows, `py -3` costuma selecionar Python 3; em Linux/macOS, use `python3`.

**Competências observáveis:** criar um arquivo `.py`, executar no diretório certo, prever o resultado dos blocos `if` e corrigir erro de sintaxe sem apagar o arquivo.

### Um passo por vez

1. Crie uma pasta `primeiros-passos` e salve nela a cópia de `PY-01.py` do laboratório.
2. Abra um terminal nessa pasta e execute `python3 --version` (ou `py -3 --version` no Windows).
3. Execute `python3 PY-01.py`. Anote literalmente a saída — duas linhas na versão original.
4. Abra o arquivo e mude somente `quantidade = 3` para `quantidade = 0`.
5. **Antes de executar**, escreva a previsão. Então rode de novo e compare.
6. Desfaça a alteração e confirme a saída inicial. Esse último passo é o **reteste**.

**Exemplo resolvido:** em `quantidade=3`, a expressão `3 > 0` é verdadeira, logo o print com recuo aparece; `print("Fim")` aparece sempre porque está fora do bloco. Em `quantidade=0`, `0 > 0` é falso e a linha recuada não roda; `Fim` permanece.

### Prática parcialmente guiada

No arquivo copiado, troque `nome = "Ana"` por `nome = "Bia"` e preveja exatamente a linha alterada. Depois escreva `print(f"Nome: {nome}")` sem recuo ao final e responda: ela depende do `if`? **Não**, por estar fora do bloco.

**Modo seguro de experimentar erro:** em uma **cópia**, remova o recuo do `print` imediatamente após `if`. Você deve receber `IndentationError` porque falta corpo indentado. Recupere a cópia corrigindo os quatro espaços; use `python3 -m py_compile PY-01.py` como verificação de sintaxe e execute novamente — compilar não prova o comportamento.

### Exercício independente (não é o mesmo exemplo)

Crie `bilhetes.py`: defina `participante = "Lu"` e `bilhetes = 2`. Imprima `Lu possui 2 bilhetes` somente quando `bilhetes > 0`, e imprima `Conferência encerrada` em **todos** os casos. Teste com `bilhetes = 2` e `bilhetes = 0` e registre as saídas. **Critérios:** duas linhas no positivo, só a final no zero, nenhuma exceção e mesmo arquivo executado nos dois casos.

**Uma solução possível (consulte depois):**

```python
participante = 'Lu'
bilhetes = 2
if bilhetes > 0:
    print(f'{participante} possui {bilhetes} bilhetes')
print('Conferência encerrada')
```

Não aceite uma solução que apenas imprime duas linhas fixas: a decisão deve depender de `bilhetes`.

Também verifica que o texto de encerramento não depende do bloco condicional. ### Quiz de transferência

1. Ao mudar `quantidade` para zero, qual linha permanece? **Somente `Fim`.**
2. Mudar aspas de `"Ana"` para `'Ana'` muda o tipo? **Não**, ambas representam texto.
3. `quantidade = "3"` seguido de `quantidade > 0` funciona como inteiro? **Não**, texto e inteiro não são diretamente comparáveis com `>` em Python 3; espere `TypeError`.
4. `py_compile` encontrou sintaxe válida. O comportamento de saída já está comprovado? **Não**, ainda é necessário executar casos.
5. `if quantidade > 0:` está correto mas a linha seguinte não tem recuo. Qual tipo de erro procurar? **IndentationError**.
