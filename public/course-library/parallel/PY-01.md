## Problema e objetivo

Execute um arquivo Python que cumprimenta Ana e informa três itens. A competência desta aula é salvar código, invocar o interpretador correto e explicar quais linhas pertencem ao bloco condicional.

## Mecanismo e exemplo resolvido

Python lê o arquivo fonte UTF-8 e interpreta as instruções em ordem. `nome` recebe texto; quantidade recebe inteiro. Os dois pontos abrem o bloco do if e os quatro espaços colocam o primeiro print dentro dele. O segundo print está alinhado com if e executa independentemente da condição. Aspas delimitam texto; a f-string avalia os nomes entre chaves.

Com quantidade=3, a condição é verdadeira e a saída tem duas linhas: `Olá, Ana: 3 itens` e `Fim`. Com quantidade=0, o primeiro print é pulado e somente `Fim` aparece. Não escreva o marcador `>>>` do console interativo no arquivo.

```python
# Salve este arquivo como primeiro.py em UTF-8.
nome = "Ana"
quantidade = 3
if quantidade > 0:
    print(f"Olá, {nome}: {quantidade} itens")  # quatro espaços: corpo do if
print("Fim")  # fora do bloco: executa mesmo com quantidade zero
```

## Prática e autoexplicação

Preparação: instale Python 3 pelo instalador oficial ou gerenciador de pacotes do sistema. Em Windows, verifique `py -3 --version` e use `py -3 "PY-01.py"`; Linux/macOS usam os comandos abaixo. Parcial: altere somente quantidade para zero e preveja a saída. Independente: adicione uma linha fora do bloco que imprima o nome. Autoexplicação: como a posição do segundo print determina se Fim aparece?

## Solução comentada e checkpoints

Checkpoint 1: a versão deve começar por Python 3. Checkpoint 2: o arquivo executado deve ser PY-01.py, não PY-01.py.txt. Zero imprime somente Fim. A linha `print(nome)` sem recuo imprime Ana nos dois casos. Remover o recuo da primeira linha do bloco causa IndentationError, não uma decisão falsa.

## Robustez, reteste e diagnóstico

Se o comando não existir, revise a instalação/PATH ou o launcher py. Se o arquivo não for localizado, rode no diretório do arquivo ou passe caminho absoluto entre aspas. Não misture tabs e espaços. `python3 -m py_compile "PY-01.py"` detecta erro de sintaxe, mas não prova a saída; execute os casos 3 e 0 após ajustar a indentação.

## Quiz

1. **Qual linha roda quando quantidade=0?**
   - A) nenhuma
   - B) somente print("Fim")
   - C) ambos os prints

2. **O que determina o corpo do if?**
   - A) todas as linhas até o fim do arquivo
   - B) apenas a linha imediatamente após if
   - C) indentação após dois pontos

3. **Por que verificar --version?**
   - A) para confirmar qual interpretador executará
   - B) para validar a sintaxe do script sem executá-lo
   - C) para selecionar automaticamente a venv do diretório

**Gabarito comentado:** 1: B — o print sem recuo está fora do if. 2: C — o recuo delimita o bloco. 3: A — o comando identifica o runtime disponível.
