## Problema e objetivo

Conte os itens de três caixas com quatro unidades e produza um executável C. Você deve distinguir fonte, declaração, expressão, chamada e status do processo.

## Mecanismo e exemplo resolvido

`#include` insere declarações do header durante o pré-processamento. main é a função inicial de um programa hospedado; void informa ausência de parâmetros. O corpo usa chaves; statements terminam com ponto e vírgula. caixas recebe 3, itens recebe o produto 12. printf formata o int com %d e emite uma quebra de linha. return 0 termina main informando sucesso.

O compilador traduz o fonte e o ligador resolve a chamada de biblioteca. O arquivo C-01.c é texto; C-01 é o programa gerado. Sua execução imprime exatamente `itens=12`. Alterar o fonte sem recompilar mantém o comportamento do executável antigo.

```c
#include <stdio.h>  /* declara printf; não executa uma impressão */
int main(void) {    /* ponto de entrada, sem argumentos usados */
    int caixas = 3;
    int itens = caixas * 4; /* expressão avaliada e armazenada */
    printf("itens=%d\n", itens); /* %d corresponde a int */
    return 0;      /* status de sucesso para o processo chamador */
}
```

## Prática e autoexplicação

Parcial: altere caixas para 5, recompile e preveja a linha de saída. Independente: introduza uma variável itens_por_caixa em vez do literal 4. Autoexplicação: por que #include não produz saída no terminal?

## Solução comentada e checkpoints

Cinco caixas produzem itens=20. A nova expressão é caixas*itens_por_caixa. Checkpoints: compilação deve terminar sem warnings; execução retorna status 0. No shell, consulte `echo "$?"` imediatamente após executar para observar o status.

## Robustez, reteste e diagnóstico

Se houver erro antes de }, procure ponto e vírgula na linha anterior. Se surgir implicit declaration de printf, revise stdio.h. Use formato compatível com o tipo; warnings não são decoração. Reteste 0 e 5 caixas após recompilar. Valores enormes podem ultrapassar int; esta aula limita as entradas às constantes pequenas fornecidas.

## Quiz

1. **O que return 0 informa aqui?**
   - A) quantidade zero
   - B) status de sucesso
   - C) número de bytes que printf escreveu

2. **O que precisa ocorrer após alterar o fonte?**
   - A) executar o arquivo .c diretamente como se fosse um script
   - B) apenas executar o binário antigo
   - C) recompilar e executar o novo binário

3. **Qual formato corresponde a int?**
   - A) %d
   - B) %s
   - C) %p

**Gabarito comentado:** 1: B — é o resultado do processo para o chamador. 2: C — o binário não acompanha a edição automaticamente. 3: A — printf precisa do formato compatível.

## Flashcards

- **Header** → Fornece declarações usadas pelo compilador.
- **Statement** → Instrução no corpo; frequentemente termina com ponto e vírgula.
- **Executável** → Resultado compilado e ligado, distinto do arquivo fonte.
