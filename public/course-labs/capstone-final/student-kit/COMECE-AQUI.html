ARTISYS ACADEMY / ESCOLALAB

Seu laboratório real, no seu computador.

Você vai iniciar um pequeno servidor HTTP e verificar por que Bob não deveria abrir uma fatura que pertence a Alice. Tudo acontece em 127.0.0.1, com dados fictícios.

1. Prepare o computador

Instale Node.js 22 ou superior se ainda não tiver. Não precisa de Docker, contas, API paga, banco de dados ou internet durante os exercícios (após instalar o Node).

2. Inicie com o arquivo do seu sistema
  • Windows: clique duas vezes em iniciar-windows.bat.
  • macOS: abra Terminal nesta pasta e rode sh iniciar-linux-mac.sh. O arquivo iniciar-macos.command é um atalho alternativo, caso o sistema permita a execução.
  • Linux: no terminal, entre nesta pasta e rode sh iniciar-linux-mac.sh.

Se o sistema pedir permissão de firewall, não libere acesso público: o servidor usa exclusivamente a interface local.

3. Abra no navegador

Com o terminal aberto, visite http://127.0.0.1:4191. Não abra index.html diretamente: ele depende do servidor local.

Selecione Alice/Bob e modo vulnerável/corrigido. Clique em Executar. O resultado exibido vem de uma requisição HTTP real ao servidor que você iniciou.

4. Guarde sua evidência

Complete os quatro passos, clique em Exportar evidências e salve o JSON em uma pasta sua. Volte à aula na Academy para continuar. Você não precisa enviar dados privados.

5. Encerre o ambiente

Volte ao terminal e pressione Ctrl+C. Para reiniciar a missão, use o botão da interface; para reiniciar o servidor, execute o inicializador novamente.

Se algo não funcionar

Se aparecer “node não encontrado”, instale o Node.js e reinicie o terminal. Se a porta 4191 estiver ocupada, feche o outro EscolaLab em execução. Se o navegador não abrir, confira o endereço e veja se o terminal continua mostrando o servidor ativo.

Importante sobre segurança

Este app é intencionalmente vulnerável no modo didático. Os nomes Alice/Bob são parâmetros simulados, não autenticação real. Ele não representa um sistema seguro para produção e não deve ser hospedado na internet, integrado a aplicativos reais ou testado contra terceiros.
