# Prova independente — módulo 08

Responda sem consultar gabarito. Cada questão vale 0, 1 ou 2 pontos. Critério recomendado: **10/12 pontos** e nenhum erro eliminatório.

1. Quais itens compõem um pacote de publicação?

2. Quando declarar mídia alterada ou sintética?

3. Como diferenciar originalidade de simples escala?

4. Que métrica evidencia problema na abertura?

5. O que implica usar a API do YouTube?

6. Dê um checklist de não-publicação para riscos editoriais.

**Erro eliminatório:** propor publicação sem direitos, consentimento ou checagem factual; tratar serviço pago como obrigatório.
