# Laboratórios A — aulas 201 a 210

**Obrigatório: gratuito, local, Node.js 22+, sem dependências npm, credenciais ou rede.**

Da raiz: `node --test public/course-labs/a201-210/lab.test.mjs`.

As funções em `models.mjs` são **modelos de decisão sintéticos**, não executam LLMs, API externa, servidor, embeddings, banco, agente real ou validação criptográfica. Não confundir um teste de contrato local com prova de segurança em produção. Cada aula exige prever o resultado, executar casos autorizados/bloqueados, explicar o controle causal e refazer o teste após uma alteração defensiva.

Gabaritos: `answer-keys/AULA-201.md` até `AULA-210.md` (fora do texto de aula). 201–208 formam a trilha de AI Security; 209–210 iniciam o capstone **independente** com escopo e threat model. As extensões com ChatGPT/Claude/LLM local, Docker ou bancos são optativas e não são necessárias para nota A.
