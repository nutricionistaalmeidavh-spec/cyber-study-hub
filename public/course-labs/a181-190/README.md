# Oficinas 181–190 — Red/Purple Team

Todos os laboratórios são offline e inertes. Node.js 22+ e arquivos deste diretório bastam.

```bash
node --test public/course-labs/a181-190/lab.test.mjs
```

Para cada aula, chame `runWorkshop(N)` em um script Node ESM e compare os cenários positivo e negativo. Não há conta externa, tráfego de rede, tarefas agendadas reais, exploração, senhas, execução de comandos ou instalação obrigatória de ferramenta paga.

Esta é uma simulação de políticas e telemetria. Não atribua incidente real a qualquer status retornado.
