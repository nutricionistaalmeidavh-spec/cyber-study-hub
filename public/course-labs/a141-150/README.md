# Aulas 141–150: oficinas offline de análise defensiva

O núcleo obrigatório usa **Node.js 22+**, é gratuito, não inicia rede, não instala ferramentas, não manipula memória e não executa malware.

```sh
node public/course-labs/a141-150/run.mjs 141
node --test public/course-labs/a141-150/lab.test.mjs
npm run test:a-141-150
npm run test:grade-a-141-150
```

Cada execução retorna `allowed`, `contrast`, `limit` e `liveMalwareExecuted:false`. Todas as medições são sintéticas. As perguntas ficam nas aulas, com gabaritos separados em `answer-keys/`.
